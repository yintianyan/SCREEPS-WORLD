# RESEARCH_SYNTHESIS · Phase 0 综合结论

> 回答总任务书（Phase 1 §2）的六个问题。依据：[RESEARCH_INDEX.md](RESEARCH_INDEX.md)
> 索引的 35 份文档全文。结论分四档：**可靠（可入工程） / 建议（可入工程但数值待校准）
> / 争议（已裁决但存在社区分歧） / 待验证（进入工程前或首个 soak 期必须复核）**。

## 1. 哪些结论真正可靠？（多源 CONFIRMED 收敛，可直接作为架构地基）

1. **两级决策结构**（帝国管战略/跨域仲裁，房间管本地闭环）——7 家 bot 无一例外
   （02 号收敛 C1）；ADR-001。
2. **孵化与角色解耦的集中优先级队列**——6 家收敛（C2）；唯一写者使全局核算与幂等
   成立；ADR-005。
3. **miner|hauler 分工 + link 网 + 请求池物流近似解**——5 家收敛（C3）+ hauling
   NP-hard 论证（12 号）；ADR-006。
4. **三级存储与瘦 Memory**——官方成本事实（parse/stringify 计税、global 随时重置、
   segment 异步）+ TooAngel 反例 + 全社区惯例；ADR-010。
5. **轻量内核语义**（调度/隔离/预算/迁移四职能，否决 OS 进程载体）——战绩证据
   不对称（19 号）；ADR-002。
6. **能力相变驱动的房间 phase**——RCL 门禁表是引擎事实（03 号），发展锚定相变点
   是社区成熟阶梯映射（10 号）。
7. **防御=能量会计 + 威胁分级状态机**——围城耗能战例 + safemode/nuke 语义为引擎
   事实（15 号）；ADR-009 的止损链。
8. **扩张=投资决策 + 资源门控**——TooAngel EMA 门控十年验证 + 社区过度扩张死因
   案例（17 号）；ADR-008。
9. **CPU 降级链**（四档看门狗、保 spawn 优先、远矿先砍）——头号死因的直接防线
   （19/20 号）；ADR-012。
10. **唯一写者 + 幂等键的所有权模型**——重复 tick/global reset/部分失败不产生重复
    对象（26 号）；红队 A12 确认。
11. **LLM/Agent 边界**——物理否决 + 社区零先例 + 判据收敛（23 号）；ADR-011。
12. **测试纯函数律**——决策与 Game 解耦使 L1–L6 测试层级成立（28 号）。

## 2. 哪些只是建议？（方向可靠、数值或细节为初值）

- 道路热度阈值（主干 200/支线 500 次通行）——SPECULATION 初值，需 soak 校准（13 号）。
- 每房 CPU 预算公式 B=U−F−C 的权重——结构可靠、参数待实测（20 号）。
- 三档节奏判据 N≈尺度÷4——启发式，个别系统需偏离（20 号）。
- 遥测阈值（≤3% limit、窗口长度）——先验值，待 A5 soak 回填（21 号）。
- 远矿 ROI 模型（~1 CPU/房定价）——数据点来自玩家个案，需自身遥测校准（17 号）。
- Intel TTL 分档数值——框架可靠、档位待校准（14 号）。
- 「RCL8 约 3 周」等时长经验值——环境相关（10 号）。

| 争议 | 阵营 | 本研究裁决 | 裁决性质 |
| --- | --- | --- | --- |
| 按房 vs 全局孵化队列 | KasamiBot（按房，长期存活）vs TI/hivemind（集中） | 全局唯一写者 | 框架选择（帝国核算需要），非社区共识 |

## 4. 哪些研究结果相互冲突？（套件内部冲突与调和记录）

1. **数据流链序**：早期表述「Goal→Policy→Demand→Agenda→Task」与 08 号环模型冲突
   → 调和为环：Policy 授权开 Agenda，Agenda 与房间稳态共同生成 Demand（触发立项
   的 Demand 例外）。
2. **link 冷却**：03 号早期版本「固定 1 tick」vs 引擎源码 → 裁决 1×切比雪夫距离。
3. **pixel 成本**：论坛 5000 vs 引擎 10000 → 10000。
4. **power bank 上限**：wiki 500–10,000 vs 引擎 5000 → 5000。
5. **TooAngel 三指标出处**：Design.html 不含、在源码 main.js/brain_nextroom.js
   → 引用精确到源码文件（06 号）。
6. **bot 计数口径**：「六大」vs 实际 7 家（含 hivemind）→ 统一「全部调研对象 7 家」。
7. **远矿归属**：09 号 Open Question vs 17 号裁决 → 远矿=母房 Operation 属地、帝国立项。

## 6. 哪些设计已经可以进入工程阶段？

- **全部 P1（运行时基座）**：内核四职能、三级存储、迁移规范、组合根、看门狗——
  规范已到可实现精度（19/18 号 + ADR-002/010）。
- **全部 P2（生存闭环）**：声明式 RolePolicy 钩子集、静态矿工经济、集中 spawn
  （census→demand→horizon 管道）、交通仲裁语义（08/11/09 号）。
- **P3–P4 骨架**：请求池物流契约（12 号）、phase 推进逻辑、建造配额与版本化蓝图
  规范（13 号）。
- **横切系统**：CPU 执行模型（20 号）、测试架构 L1–L6 与 S1–S10（28 号）、遥测
  管线（21 号）、自愈六动作/六禁令（22 号）。
- **暂缓**：P5+（远矿/扩张/军事）的参数层——契约已定，数值待前置系统遥测。
