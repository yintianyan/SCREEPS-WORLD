# E2E_ENV_BASE_CONTRACT · E2E 环境基座与注入架构（设计合同 · 待 ADR 冻结）

> 状态：**已冻结（R19，2026-08-30）**——登记见
> [ARCHITECTURE_FREEZE.md](../architecture/ARCHITECTURE_FREEZE.md) §15。
> 背景：SOAK_START_RCL 预置 RCL7 被当自然状态解读的失真教训（素房 1W upgrader
> 速率外推 RCL8 时长被证伪）；夹具动物园（standardRoom/rcl4Room/… 各自为政）
> 导致场景间不可比。

## 1. 分层架构

| 层 | 职责 | 构造权 |
| --- | --- | --- |
| L0 基座 | t0 真实环境唯一标准答案：spawn(300)+controller+2 source+mineral，从真实游戏新 spawn 房推导，不承载任何场景假设 | `fixtures/base.ts` 唯一构造器，**全仓唯一** |
| L1 环境注入 | 场景显式声明的预设：RCL 等级、storage 水位、GCL、CPU limit、结构补全 | `fixtures/inject.ts` 统一 API，逐项具名 |
| L2 场景注入 | 敌袭波次、故障（删 creep/毁结构）、配额压力、war 态势 | 同上（addHostileCreep/removeCreeps/setUserCpu 收编） |
| 隔离 | 每测试实例独立 server（tmpdir+随机端口） | 注入只作用于本实例，场景零串扰 |

基座参数裁决：L0 固定 **一个 canonical 房**（2 源平原）保主轨可比性；
「1 源房 / SK 邻房 / 特殊地形」等变体一律降格为 L1 显式环境注入，不建第二基座。

## 2. 注入分级（权限模型）

| 级别 | 通道 | 合法用途 | 禁止 |
| --- | --- | --- | --- |
| 白名单注入 | 引擎合法语义（addHostileCreep / setUserCpu / DB 对象操作） | 构造前提 + 驱动场景 | — |
| 测试后门 | console/DB 直改 Memory、内部状态 | **仅限构造前提**（如预置 buildQueue） | **出现在被断言的执行路径上**——否则测试验证的是自己的注入 |

每条注入具名登记于场景证据行；review 时按本表可查。

## 3. 证据效力矩阵（铁律）

| 轨 | 证据范围 | 禁止外推 |
| --- | --- | --- |
| 自举轨（t0 无注入长程） | 动态/历史结论：爬级节奏、经济速率、tuning 演化、Memory 长期行为 | — |
| 注入轨（L1/L2 环境） | 静态环境下的**行为正确性**（门槛执行、配额封顶、故障隔离、授权门） | **不得外推动态/历史结论**（速率、节奏、演化）——「预置当自然」的制度性堵死 |

所有证据行标注：环境档（自举/注入具名）+ mockup 保真度边界（引擎记账/invader AI/
市场流动性与官方存在已实测差异；Soak-Verified 终审以官服 soak 为准）。

## 4. 基座变更纪律

基座 = 证据基线：任何 L0/L1 API 语义变更走 FREEZE §15 ADR + 版本绑定；
存量证据行随之标注「基座 vX 前/后」。基座不得静默漂移。

## 5. 自举轨产出模式（机器时间制度化）

自举轨一次铸全程：t0 → RCL8 无注入长跑（一晚量级），产出全程遥测 + 分阶段
census（结构普查对照 layout 契约，作证据完整性校验），绑 commit 后作为该版本
**自举证据工件**长期有效。此后基座+注入轨只做行为验证，不重复自举成本。
代码大版本 → 重铸。census 不是基座构造器——环境真实性由代码自举保证。

## 6. 存量迁移纪律

新场景强制 base+inject 写法；存量场景「触摸即迁移」（改哪个迁哪个），不做
一次性 big-bang；SOAK_START_RCL 类隐藏预设全部显式化为 L1 具名注入。
